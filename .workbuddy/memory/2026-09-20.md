## AntSDR E316 烧录 openwifi —— 调研与指南产出

**目标**：为 AntSDR E316 开发板给出可执行的 openwifi 烧录流程。

**关键结论（已验证）**
- **AntSDR E316 == AntSDR E310V2**。依据：微相文档中心产品列表 `E310V2 (E316)`；`antsdr-fw-patch` 编译说明 `ANTSDR E316(E310V2)` → `TARGET=e310v2`。
- openwifi 侧对应板名 **`e310v2`**，官方 master 与 v1.5.0 都已有该板级支持，无需改代码。
  - `openwifi/kernel_boot/boards/e310v2/`（devicetree.dts/dtb、u-boot.elf）
  - `openwifi-hw/boards/e310v2/`、`openwifi-hw-img/boards/e310v2/sdk/system_top.xsa`
  - 设备树 `model = "ANTSDR-E310V2"`，`setup_once.sh` 靠该字符串选板
- 不要用 `antsdr`（那是老 E310）。
- Zynq-7020 → Vivado 授权 **不需要**；`ARCH_BIT=32`。

**两条烧录路线**
- 路线 A（预编译镜像）：`openwifi-1.5.0-shahecheng.img.xz`，3.3 GB → 解压 15.9 GB，SD ≥16 GB。烧完把 `BOOT/openwifi/e310v2/` 下的 `BOOT.BIN`、`devicetree.dtb`、`system_top.bit.bin` 拷到 BOOT 根目录。默认 `root/openwifi`，板 IP `192.168.10.122`，PC 侧 `192.168.10.1`。
- 路线 B（Buildroot，master 新增）：`./buildroot-build.sh e310v2 build` → `openwifi-e310v2-sdcard.img`（约 169 MB），无需手工覆盖 BOOT 文件，不需 Vivado；要求 Linux x86_64 主机。
- 本机是 macOS，ext4 分区挂不上 → 官方要求的“删 rootfs/root/kernel_modules 与 etc/network/interfaces.new”可跳过（前者 setup_once.sh 自建，后者串口进板子删）。

**产出文件**
- `ANTSDR-E316-openwifi-烧录指南.md`（含两条路线、A7 FPGA/驱动升级步骤、排错表、参数速查）

**踩坑记录**
